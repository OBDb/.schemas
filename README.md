# OBDb schemas

This repository contains the full set of specifications for the OBDb.

## Proposed conventions

- [Polling categories](docs/polling.md): six proposed interval categories,
  classification rules for contributors and agents, and worked fleet examples.
  This is a documentation proposal; the signalset schema and existing vehicle
  intervals are unchanged. See the [review notes](docs/polling-review.md) for
  scope and decisions before adoption.
